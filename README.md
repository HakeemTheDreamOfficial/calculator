## Fun, cool, calculator project

I tried not to use the eval() function specifically to try to make the code myself originally

#Features
-Inputs floats or integers
-Doesn't allow division by zero
-Operates in PEMDAS order
-Can do multiplication, division, addition and subtraction

##How to run

Run:

```bash
python calculator_v1.py
```
